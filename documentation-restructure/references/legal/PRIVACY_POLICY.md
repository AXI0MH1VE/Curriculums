# Privacy Policy: Documentation Restructuring Agent (DRA)
> Timestamp (UTC): 2026-03-27T02:15:16Z

## 1. Data Collection and Usage
The Documentation Restructuring Agent (DRA) processes text provided by the user for the sole purpose of restructuring and stylistic refinement. 

## 2. Ephemeral Processing
All input text and generated output are processed ephemerally. The DRA does not store, retain, or "learn" from user-provided data once the session is concluded.

## 3. No Third-Party Sharing
Data processed by the DRA is not shared with third-party advertisers or external entities, except where necessary for the underlying LLM infrastructure to function (e.g., standard API calls to the model provider).

## 4. Data Integrity
Users should avoid inputting highly sensitive, personally identifiable information (PII) or confidential secrets into the DRA, as outputs may inadvertently rephrase or highlight such data in ways that could be problematic in a final document.

## 5. Changes to This Policy
This policy may be updated as the DRA's capabilities or the underlying infrastructure evolve.
